# 触达事件和身份更正

event_id由曝光源生成，跨重传批次保持不变。source_key包含来源命名空间，因此不同渠道相同文本标识不当然代表同一人。person是已确认的分析主体，不是用相似行为猜测的身份。

撤销事件针对指定event_id，替换传输批次不撤销该业务含义。身份合并或撤回合并针对明确的一组来源标识关系，合并无效不代表参与者的曝光事件无效。当前日汇总支持稳定映射和新增事件，不把日度人数声明为可加。

周按ISO日历周，周一开始；事件day在来源规范化后已经是约定的同一业务日期，不进行时区猜测。渠道组合查询的人数表示所选渠道并集里的不同分析主体，而不是各渠道人数之和。无效事件不贡献曝光次数或人数，封存摘录只重现当时口径。
